# 건강의 개념 — 인터랙티브 학습 게임

건강이와 대화하며 건강의 개념을 배우는 한국어 선택형 학습 게임입니다. 주제를 선택하고 설명을 읽은 뒤 퀴즈를 풀어 점수를 모을 수 있습니다.

## 실행

정적 사이트입니다. index.html을 브라우저에서 열면 바로 플레이할 수 있습니다. 외부 API 키나 빌드 과정은 필요하지 않습니다.

## 배포

Vercel에서 이 저장소를 가져오면 기본 설정으로 배포할 수 있습니다.
